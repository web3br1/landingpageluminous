# Sprite Style Guide

## Art Direction

Sprites must look like production assets for a Nintendo DS-era tactical RPG monster battler. The art should be compact, readable, energetic, and intentionally limited.

## Camera

- Tactical 3/4 view.
- Shared ground plane.
- Combat-facing pose language.
- No dramatic perspective changes between frames.

## Shape Language

- Strong silhouette first.
- Large readable masses before small detail.
- Distinct head, torso, limbs, tail, ears, horns, flame, hair, armor, or accessory shapes.
- Avoid noisy clusters that only look good when zoomed in.

## Shading

- Use controlled two-to-four-step ramps.
- Use shadows to define form, not to simulate painterly light.
- Highlights should be sparse and intentional.
- Dithering is only allowed if deliberate, minimal, and style-consistent.

## Effects

- Effects must be pixel-art effects, not rendered particles.
- Elemental effects should have compact silhouettes.
- Effects should communicate attack type without hiding the character.
