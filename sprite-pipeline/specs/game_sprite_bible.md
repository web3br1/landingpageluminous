# Game Sprite Bible

All characters must share:

- same tactical 3/4 camera
- same pixel density
- same outline logic
- same palette density
- same animation state structure
- same frame spacing
- same combat readability
- same atlas organization
- same transparent background
- same grid readability

No character may look like it belongs to another game.

## Global Style Lock

The game style is fixed before any character interpretation begins. Character references influence identity, silhouette, proportions, accessories, and expression, but never override the shared game language.

## Production Standard

Each approved sprite sheet must feel like part of one coherent tactical monster battle roster. Any sheet that changes rendering style, camera perspective, outline behavior, pixel density, or palette logic should be rejected or regenerated.
