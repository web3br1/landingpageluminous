# Quality Checklist

Use this checklist before approving any generated sprite sheet.

## Identity

- [ ] Character identity is recognizable from the reference.
- [ ] Core silhouette is preserved.
- [ ] Iconic accessories, markings, species traits, or elemental motifs are retained.
- [ ] Personality expression is readable.

## Style Consistency

- [ ] Matches the shared tactical 3/4 camera.
- [ ] Matches the shared pixel density.
- [ ] Matches the shared outline logic.
- [ ] Matches the shared palette density.
- [ ] Looks like it belongs to the same game as the other roster sprites.

## Atlas Quality

- [ ] Background is transparent.
- [ ] Atlas uses a clean grid.
- [ ] Frame cell size is consistent.
- [ ] Baseline and center alignment are consistent.
- [ ] All required animation states are present.
- [ ] Frames can be sliced reliably.

## Readability

- [ ] Silhouette reads clearly at gameplay scale.
- [ ] Limbs and accessories do not merge into the body.
- [ ] Attack intent is readable.
- [ ] Effects do not obscure the character.
- [ ] No over-detailed texture noise.

## Rejection Checks

- [ ] No painterly shading.
- [ ] No smooth gradients.
- [ ] No vector or 3D-render look.
- [ ] No AI mush pixels.
- [ ] No inconsistent anatomy between frames.
- [ ] No inconsistent camera angle between frames.
- [ ] No inconsistent outline thickness.
- [ ] No background scenery, UI, labels, or decorative borders.
