# Negative Prompt

Avoid:

- blurry pixel art
- AI-generated mush pixels
- inconsistent frame anatomy
- inconsistent camera angle
- inconsistent outline thickness
- painterly shading
- smooth gradients
- vector art
- 3D render look
- semi-realistic rendering
- noisy details
- unreadable silhouette
- merged limbs
- overcomplicated textures
- random dithering
- different proportions between frames
- different palette between frames
- background scenery
- decorative UI
- non-transparent background
