# Character Reference Prompt Template

Use this template when a source image or character description is provided.

## Instruction

Analyze the provided character reference and convert it into the fixed tactical monster battle sprite style. Preserve identity, silhouette, personality, proportions, and iconic features, but do not copy the source rendering style.

## Required Analysis

Return:

1. Species or archetype read
2. Core silhouette notes
3. Head, face, and expression notes
4. Body proportion notes
5. Iconic markings, accessories, or elemental motifs
6. Combat personality
7. Risks for sprite readability
8. Simplification plan for small-pixel gameplay readability

## Prompt Insert

```text
Character reference: [describe uploaded image or file path]
Preserve: [identity, silhouette, expression, proportions, accessories]
Adapt into: fixed tactical monster battle sprite language defined by the project bibles and specs.
Do not adapt the game style to match the reference.
```
