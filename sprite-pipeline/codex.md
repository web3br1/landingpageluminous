# Codex Instructions — Tactical Monster Sprite Pipeline

You are assisting with a dedicated sprite generation pipeline for a competitive 3v3 monster battle game.
Your job is to help generate, refine, validate, and standardize prompts and assets for retro tactical pixel-art sprite sheets.

## Core Visual Target

All generated sprites must follow:

- Pokémon Mystery Dungeon GBA/NDS readability
- Fire Emblem GBA combat clarity
- Golden Sun battle energy
- tactical board-game silhouette readability
- handcrafted pixel-art atlas presentation

The final output must look like a professional Nintendo DS-era tactical RPG sprite atlas.

## Main Rule

Never generate generic “beautiful pixel art”.
Always generate production-ready sprite atlas prompts with strict constraints for:

- silhouette
- camera angle
- outline
- palette
- animation states
- combat readability
- frame consistency
- transparent background
- atlas organization

## Required Animation States

Every character sprite sheet must include:

1. Idle
2. Movement
3. Physical Attack
4. Special Attack
5. Hurt
6. Sleep
7. Knockout / Defeat
8. Victory Pose

## Reference Fidelity

When the user provides a photo or character image, preserve:

- core silhouette
- facial structure
- species identity
- body proportions
- iconic accessories
- personality expression

But adapt everything into the game’s fixed sprite language.
Do not change the game style to match the reference.

## Output Standard

Whenever asked to create a sprite prompt, return:

1. Character interpretation
2. Visual constraints
3. Master generation prompt
4. Negative prompt
5. Atlas layout instructions
6. Quality checklist
7. Optional variation prompts

## Forbidden Output

Avoid:

- painterly textures
- smooth gradients
- vector look
- inconsistent anatomy
- inconsistent outline thickness
- random AI mush pixels
- different camera angles between frames
- disconnected animation frames
- over-detailed unreadable sprites
