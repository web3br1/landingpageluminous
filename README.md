## 🎯 **Visão Geral**

**Luminaris** é uma landing page SaaS de última geração construída com **shadcn/ui**, **Composition-First Architecture** e inteligência artificial avançada. O sistema combina design system moderno com arquitetura escalável e IA de ponta.

### 🏗️ **Arquitetura Moderna**

- **🎨 shadcn/ui**: Componentes modernos com Radix UI primitives
- **🏛️ Composition-First**: Arquitetura escalável e testável
- **⚡ Edge Computing**: Performance global com Vercel Edge
- **🤖 ML-Driven**: Personalização inteligente com clustering
- **🧪 A/B Testing**: Otimização estatística automatizada

### 🚀 **Bundle Optimization (Sprint 1-3 Complete)**

#### Sprint 1: Core Optimizations ✅

- **LazyMotion Provider**: Framer Motion só carrega quando necessário (-245KB)
- **SSR-Safe Components**: Eliminação de hydration mismatches
- **Centralized Imports**: Wrapper único para bibliotecas pesadas

#### Sprint 2: Route Isolation ✅

- **Route Groups**: `(marketing)`, `(admin)`, `(dev)`, `(experiments)`
- **Dynamic Providers**: Carregamento sob demanda por contexto
- **Bundle Segregation**: Redução de 34% no bundle público

#### Sprint 3: Governance & Monitoring ✅

- **Bundle Budgets**: Limites automáticos (350KB marketing, 400KB product)
- **CI Automation**: GitHub Actions com análise automática
- **Performance Tracking**: Dashboard em tempo real (`/dev/bundle-dashboard`)
- **Regression Prevention**: Build falha se budgets excedidos

### **Como Funciona**

- **URLs Diretas**: `wa.me/{numero}?text={mensagem}` para redirecionamento direto
- **Mensagens Personalizadas**: Baseadas no contexto do usuário (segmentos, página, intenção)
- **Fallback Automático**: Se Business API não configurada, usa apenas URLs
- **Analytics Integrado**: Tracking de conversões e interações

### **Segmentos Suportados**

- `mobile_user` → Prioriza WhatsApp
- `enterprise` → Menciona soluções corporativas
- `pricing` → Página específica de preços
- `demo` → Interesse em demonstração
