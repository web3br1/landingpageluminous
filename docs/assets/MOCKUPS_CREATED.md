## 🎨 **COMO USAR OS MOCKUPS**

### **1. Visualizar no Navegador**

Os mockups já estão implementados na landing page e podem ser visualizados em:

- http://localhost:3000 (seção Screenshots)
- http://localhost:3000 (seção Depoimentos)

### **2. Customizar**

Para customizar os mockups, edite os arquivos SVG diretamente:

- Altere as cores nas tags `fill="#..."`
- Modifique textos nas tags `<text>`
- Ajuste posições nos atributos `x`, `y`, `transform`

### **3. Exportar para Outros Formatos**

Se necessário converter para PNG:

```bash
# Usando Inkscape (instalar primeiro)
inkscape screenshot-dashboard.svg --export-png=screenshot-dashboard.png --export-width=1200

# Usando ImageMagick
convert screenshot-dashboard.svg screenshot-dashboard.png
```
