### **2. Customizar**

Para customizar qualquer asset, edite os arquivos SVG:

```bash

```

### **3. Exportar para PNG**

Se necessário converter para PNG:

```bash
# Usando Inkscape
inkscape logo.svg --export-png=logo.png --export-width=200

# Usando ImageMagick
convert logo.svg logo.png
```
